# Example workflow

- fill PROJECT.md with project context information
- `/memory refresh` to update memory with new PROJECT.md
- `/speckit.constitution`
- `/speckit.specify create new feature "Implement somthing useful using these instruments"`
- `/speckit.clarify` to clarify any ambiguities
- `/speckit.plan` to generate a plan for the feature
- `/speckit.tasks` to generate tasks for the feature
- `/speckit.analyze` to analyze the impact of the feature on the constitution
- `/speckit.implement` to execute the tasks step by step
